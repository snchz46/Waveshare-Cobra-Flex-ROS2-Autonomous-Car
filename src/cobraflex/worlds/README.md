# cobraflex/worlds

SDF worlds for Gazebo Harmonic. Each world is loaded with:

```bash
ros2 launch cobraflex gazebo_mesh.launch.py world:=<name> gui:=true
```

`gazebo_mesh.launch.py` resolves a bare token to
`worlds/lane_following_<token>.world`; `world:=oval_complex` and
`world:=lane_following_oval_complex` are equivalent. A value that contains a
path separator or ends in `.world` / `.sdf` is passed through unchanged, which
gives access to the worlds outside the lane-following family.

## Lane-following worlds

Each track is a single textured plane; the road appearance is defined entirely
by the texture. All worlds of a family share the same geometry, so differences
in the behaviour of a camera controller originate in perception, not in the
path.

| World | Texture | Purpose |
| --- | --- | --- |
| `lane_following_oval_simple` | `tracks/complex_a.png` | Low-curvature circuit; baseline |
| `lane_following_oval_complex` | `tracks/complex_b.png` | Default in `gazebo_mesh.launch.py` and `lane_keeper_gazebo.launch.py` |
| `lane_following_complex_b_flipH` | `tracks/complex_b_flipH.png` | Horizontally mirrored circuit; steering-bias test |
| `lane_following_complex_b_flipV` | `tracks/complex_b_flipV.png` | Vertically mirrored circuit; steering-bias test |
| `lane_following_complex_b_worn_25` | `tracks/complex_b_worn_25.png` | Worn markings, strongest level (lowest line contrast) |
| `lane_following_complex_b_worn_50` | `tracks/complex_b_worn_50.png` | Worn markings, intermediate level |
| `lane_following_complex_b_worn_75` | `tracks/complex_b_worn_75.png` | Worn markings, mildest level |
| `lane_following_complex_b_gaps` | `tracks/complex_b_gaps.png` | Lane-line dropouts |
| `lane_following_complex_b_particles` | `tracks/complex_b_particles.png` | Debris and stains on the road |
| `lane_following_oval` | `road_curves/` + `road_textures/` tiles | Tiled construction (5 models) instead of a single plane, for geometry work |

The `worn_25/50/75` worlds form a degradation sweep (SC-PERT-09): the
intervention rate of one controller across the three worlds, as a function of
the degradation level, is the result of interest.

## Textures

Road textures are generated by the scripts under `materials/road_assets/`:

```bash
python3 materials/road_assets/road_tiles/make_road_tiles.py
python3 materials/road_assets/road_textures/make_road_textures.py
python3 materials/road_assets/road_curves/make_road_curves.py
python3 materials/road_assets/road_variants/make_road_variants.py
```

PNG file names contain the real size in metres (`tile_zebra_0p52m_x_4m.png`
is 0.52 m × 4 m), so a tile can be placed without determining the UV scale.

Worlds reference textures through relative paths
(`../materials/road_assets/...`), resolved against the location of the world
file. This works both in the source tree and in the install share, since
`setup.py` installs both under `share/cobraflex/`. Absolute paths work only on
the machine on which they were written.

## Procedure for a new world

1. Copy the most similar `lane_following_*.world`.
2. Set its `<albedo_map>` to the new texture, with a relative path.
3. Add the texture directory to `data_files` in `setup.py` if it is new.
4. `colcon build --packages-select cobraflex --symlink-install`.
5. Validate the world before launching it: `gz sdf -k worlds/<name>.world`.
